# Trace Analysis

This folder takes the analysis of the traces and produces results.


## Post Lifetime

The lifetime is computed at the posts that:
1. Have more that one repost.
2. Have been created not in the warmup phase


It might be beneficial to analyze with a logistic regression with in-degree, time-post-creation and some more things if we can predict if a post will live or die when it does not have repost, as the "birth" analysis
